# SystemGroupAssistantBot - Fa2SQL
Python implementation for SG Digital Assistant Fa2SQL BOT.

# How to run SG Fa2SQL BOT:

0. Clone the project ``git clone https://github.com/naserahmadi/SystemGroupAssistantBot.git`` and ``cd Rag-Bot``
1. Install the requirements by runnnig ``pip install -r requirements.txt``
2. Run the app: ``bash run_app.sh``. The app will run on port 8504 of your localhost. 

!
# How to run evaluations:
- For running the evaluations, first config your evaluations in ``fa2sql-configs.yaml`` and then run the ``fa2sql/eval.py`` script. 
- This script will run the evaluation on the selected dataset and will save the results in ``evaluation`` folder.
